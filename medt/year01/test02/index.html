HTML Grundlagen

Basics

Grundstruktur einer HTML-Seite

HTML
<!-- Pflicht: jede HTML-Datei beginnt so -->
<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">         <!-- Zeichenkodierung -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meine Seite</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- Sichtbarer Inhalt hier -->
</body>
</html>
!DOCTYPE html

Teilt dem Browser mit: "Das ist HTML5." Muss in Zeile 1 stehen.

meta charset

Zeichenkodierung → Umlaute wie ä, ö, ü funktionieren korrekt.

meta viewport

Pflicht für responsive Design — sonst wird die Seite auf Handy verkleinert angezeigt.

Semantische Tags — die wichtigsten

TagBedeutungWann nutzen?

⚠ first-child vs. first-of-type — Wichtigster Unterschied!

HTML
<div>
  <h2>Titel</h2>    <!-- erstes Kind -->
  <p>Text 1</p>  <!-- zweites Kind, erstes <p> -->
  <p>Text 2</p>
</div>
p:first-childTrifft NICHTS! Das erste Kind ist h2, kein p.
p:first-of-typeTrifft "Text 1" — das erste <p> unabhängig vom h2.

Selektor Quiz

Welches Element trifft li:nth-child(2)?
HTML
<ul>
  <li>Eins</li>
  <li>Zwei</li>
  <li>Drei</li>
</ul>
nth-child(2) zählt von 1 — das zweite Kind ist "Zwei".
Was trifft a[href$=".pdf"]?
Das $= bedeutet "endet mit". Trifft also href="dokument.pdf" aber nicht href="pdf-info.html".

Flexbox

1D Layout
Merksatz: Flexbox = 1 DimensionFlexbox ordnet Elemente in einer Richtung: entweder als Zeile (row) oder als Spalte (column).

Grundprinzip: Eltern steuert Kinder

CSS
.container {
  display: flex;               /* Flexbox aktivieren */
  flex-direction: row;         /* row (Standard) oder column */
  justify-content: center;    /* Hauptachse */
  align-items: center;        /* Nebenachse */
  gap: 16px;                   /* Abstand zwischen Elementen */
  flex-wrap: wrap;             /* Umbruch erlauben */
}

⚠ Häufige Fehler

Fehler: justify-content funktioniert nicht
/* justify-content funktioniert nicht → Warum? */

  justify-content: center; /* ← display:flex fehlt! */

Lösung
.box {
  display: flex; /* ← immer zuerst aktivieren */
  justify-content: center;

Achsen — Wenn flex-direction: column

Bei flex-direction: column drehen sich die Achsen um! justify-content wirkt dann vertikal, align-items horizontal.

CSS Grid

2D Layout
Merksatz: Grid = 2 DimensionenGrid definiert Zeilen UND Spalten gleichzeitig — perfekt für ganze Seitenlayouts.
CSS
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 gleiche Spalten */
  grid-template-rows: auto auto;          /* 2 automatische Zeilen */
  gap: 20px;                               /* Abstand überall */
}

Galerie-Beispiel

CSS

/* Responsive: auf Handy 1 Spalte */
@media (max-width: 600px) {
  .galerie { grid-template-columns: 1fr; }
}

Positionierung & Document Flow

Wichtig
WertIm Flow?BezugTypische Nutzung
static✓ JaNormalStandard — jedes Element
relative✓ JaEigene PositionLeicht verschieben, Anker für absolute
absolute✗ NeinNächster non-static ElternteilOverlays, Badges, Tooltips
fixed✗ NeinBrowserfensterSticky Navigation, Cookie-Banner
sticky✓ JaScrollbereichTabellen-Header, Sidebar

Flow-Diagramm

Welche Werte bleiben im normalen Flow?
static → Im Flow ✓ — normaler Ablauf
relative → Im Flow ✓ — Platz bleibt reserviert
sticky → Im Flow bis zum Scrollpunkt
absolute → Verlässt Flow ✗ — andere ignorieren es
fixed → Verlässt Flow ✗ — klebt am Fenster

Beispiele

CSS
/* relative: Elternteil für absolute Kinder */
.card {
  position: relative;
}

/* absolute: Badge in der Karte */
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}

/* fixed: Navigation bleibt immer sichtbar */
nav {
  position: fixed;
  top: 0;
  width: 100%;
}

/* sticky: Tabellen-Header beim Scrollen */
th {
  position: sticky;
  top: 0;
}
Prüfungsfalle: absoluteOhne position: relative am Elternteil positioniert sich absolute relativ zum <body>!
Merksatzrelative + absolute = beste Kombination. relative = Anker, absolute = Badge/Overlay.
07

Media Queries

Responsive
Mobile First — der StandardZuerst das Handy-Layout schreiben, dann mit min-width für größere Screens erweitern.
CSS — Mobile First Prinzip
/* Basis: Handy (immer aktiv) */
.container {
  display: grid;
  grid-template-columns: 1fr;  /* 1 Spalte */
}

/* Ab Tablet (768px) */
@media (min-width: 768px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Ab Desktop (1024px) */
@media (min-width: 1024px) {
  .container {
    grid-template-columns: repeat(3, 1fr);
  }
}
GerätBreakpointKeyword
HandyStandard (kein @media)Basis-CSS
Tabletmin-width: 768pxMedium
Desktopmin-width: 1024pxLarge
Großer Desktopmin-width: 1280pxXL

min-width vs. max-width

min-width (Mobile First)

Gilt ab dieser Breite. Empfohlen!

@media (min-width: 768px) {}
max-width (Desktop First)

Gilt bis zu dieser Breite.

@media (max-width: 768px) {}

⚠ Häufige Fehler bei Media Queries

  • Meta viewport vergessen → Seite wird nicht responsiv!
  • Fehlende geschweifte Klammer: @media { .x { } } — zwei Ebenen!
  • max-width und min-width verwechseln

Fehlersuche / Debugging

Find the Bug

Find the Error — HTML

Bug #1 — HTML Liste 
<ul>
  Hallo Welt
  <a href="#">Link</a>
</ul>
✓ Lösung & Erklärung

Fehler: Direkter Text und <a> in <ul> — <ul> darf nur <li> enthalten!

<ul>
  <li>Hallo Welt</li>
  <li><a href="#">Link</a></li>
</ul>
Bug #2 — Nicht geschlossener Tag 
<section>
  <h2>Titel</h2>
  <p>Erster Text
  <p>Zweiter Text</p>
</section>
✓ Lösung & Erklärung

Fehler: "Erster Text" hat kein </p> — Tags müssen immer geschlossen werden!

  <p>Erster Text</p>  <!-- </p> ergänzt! -->
Bug #3 — img ohne alt 
<img src="foto.jpg">
✓ Lösung & Erklärung

Fehler: alt-Attribut fehlt — ist Pflicht für valides HTML!

<img src="foto.jpg" alt="Beschreibung des Bildes">

Find the Error — CSS

Bug #4 — Fehlende Semikolons 
p {
  color: blue
  font-size: 16px
  background: yellow;
}
✓ Lösung & Erklärung

Fehler: Zeile 2 und 3 fehlt das Semikolon — jede CSS-Deklaration braucht eines!

p {
  color: blue;           /* ← Semikolon! */
  font-size: 16px;       /* ← Semikolon! */
  background: yellow;
}
Bug #5 — Falscher Selektor (Klassenpunkt fehlt) 
/* soll alle Elemente mit class="card" stylen */
card {
  background: lightblue;
  padding: 20px;
}
✓ Lösung & Erklärung

Fehler: "card" ohne Punkt selektiert ein HTML-Element namens <card> — nicht die Klasse!

.card {   /* ← Punkt vor dem Klassennamen! */
  background: lightblue;
  padding: 20px;
}
Bug #6 — display:flex vergessen 
.nav {
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}
✓ Lösung & Erklärung

Fehler: justify-content, align-items und gap haben ohne display:flex keinen Effekt!

.nav {
  display: flex;  /* ← Muss zuerst kommen! */
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}
Bug #7 — Falscher Bildpfad 
/* Datei liegt in: images/foto.png */
<img src="foto.png" alt="Foto">
✓ Lösung & Erklärung

Fehler: Ordner "images/" fehlt im Pfad. Auf Linux-Servern zählt auch Groß-/Kleinschreibung!

<img src="images/foto.png" alt="Foto">

Mini-Prüfung

Probe
Beantworte alle Fragen selbst, bevor du die Lösung ansiehst!

Teil A — Selektor-Fragen

1. Was trifft p:first-of-type in folgendem HTML?
HTML
<div>
  <h1>Titel</h1>
  <p>Absatz A</p>
  <p>Absatz B</p>
</div>
first-of-type trifft das erste Element dieses Typs. Das erste <p> ist "Absatz A" — unabhängig vom h1.
2. Welcher Selektor trifft alle <a> mit href, das auf ".pdf" endet?
$ bedeutet "endet mit". ^ = beginnt mit, * = enthält, = = exakter Wert.
3. Was beschreibt position: fixed korrekt?
fixed verlässt den normalen Flow und bezieht sich immer auf das Browserfenster — daher bleibt es beim Scrollen stehen.
4. Was macht grid-template-columns: repeat(4, 1fr)?
repeat(4, 1fr) = 4 Spalten, jede bekommt 1 Anteil des verfügbaren Platzes = alle gleich breit.

Teil B — Coding-Aufgaben

Aufgabe 1

Schreibe CSS, das eine Navigation mit position: fixed oben fixiert und die Links mit Flexbox nebeneinander anordnet.

CSS
nav {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  background: #333;
  z-index: 100;  /* Wichtig: über anderen Elementen! */
}

nav ul {
  display: flex;
  list-style: none;
  gap: 20px;
  padding: 14px 20px;
}
Aufgabe 2

Erstelle ein responsives 3-spaltiges Grid-Layout, das auf Handy (unter 768px) einspaltig wird.

CSS
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

@media (max-width: 768px) {
  .container {
    grid-template-columns: 1fr;
  }
}
Aufgabe 3 — Vollständige HTML-Seite

Schreibe eine vollständige HTML-Seite mit: Navbar (fixed), section mit Überschrift + Text, article mit Bild + Name, footer.

HTML + CSS
<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meine Seite</title>
  <style>
    * { box-sizing: border-box; }
    body { margin: 0; font-family: sans-serif; }
    nav {
      position: fixed; top: 0; width: 100%;
      background: #222; padding: 10px 20px;
    }
    nav ul { display: flex; list-style: none; gap: 20px; margin: 0; }
    nav a { color: white; text-decoration: none; }
    main { margin-top: 60px; padding: 20px; display: grid;
           grid-template-columns: repeat(2, 1fr); gap: 20px; }
    @media (max-width: 768px) { main { grid-template-columns: 1fr; } }
    footer { background: #111; color: #aaa; text-align: center; padding: 20px; }
  </style>
</head>
<body>
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
      <li><a href="#">Über uns</a></li>
    </ul>
  </nav>
  <main>
    <section>
      <h2>Willkommen</h2>
      <p>Hier steht der Text.</p>
    </section>

Position Cheatsheet

static
Standard. Im Flow. top/left haben keinen Effekt.
relative
Im Flow. Verschoben von Ausgangsposition. Anker für absolute.
absolute
Aus Flow. Bezug: nächster non-static Elternteil.
fixed
Aus Flow. Bezug: Browserfenster. Bleibt beim Scrollen.
sticky
Im Flow bis top: X erreicht, dann fixiert.
z-index
Stapelreihenfolge. Höher = vorne. Nur bei non-static!
